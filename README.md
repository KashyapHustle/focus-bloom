# Focus Bloom

Build a polished open-source web app called Focus Garden, a productivity timer designed for students, developers, researchers, and anyone who wants to focus on tasks. The core experience should be Create a task → choose its type → choose a focus duration → focus → grow a tree → earn Focus Coins → unlock new trees → view productivity insights. The main screen should have a large circular countdown timer with a beautiful tree growing slowly inside it as the session progresses; the tree should start as a small seedling and gradually grow into a mature tree based on the percentage of the session completed. The timer must support any duration from 1 minute up to 10 hours, with convenient presets such as 10 minutes, 25 minutes, 45 minutes, 60 minutes, 90 minutes and 2 hours, plus a custom duration option. Include Start, Pause, Resume, Reset and End Session controls, and make the timer accurate using real timestamps so it remains accurate when the browser tab is inactive or the computer is busy. Users should be able to create and select tasks before starting a session, with task categories such as Study, Coding, Research, Writing, Creative, Work, Personal and Other; the selected task and category should appear above the timer and be connected to the completed session history. The app should suggest breaks based on actual focus duration: under 25 minutes no recommendation, 25–50 minutes a 5-minute break, 50–90 minutes a 10-minute break, 90–120 minutes a 15-minute break, and more than 120 minutes a 15–20 minute break; users can accept or ignore suggestions and breaks should never be forced. Users earn exactly 10 Focus Coins for every completed minute of actual focus time, with paused time and break time excluded, so 30 minutes gives 300 coins and 2 hours gives 1,200 coins. Coins should accumulate progressively and only legitimate focused minutes should count. Create a collection of approximately 30–40 different tree types, with a carefully balanced progression system rather than random prices: the first few trees should be easy to unlock, middle trees should require a combination of Focus Coins and a certain number of previously unlocked trees, advanced trees should require more coins plus more unlocked trees and possibly total focus-time milestones, and the final rare or legendary trees should require significant but achievable long-term progress such as higher coin amounts, more unlocked trees, total focus hours and possibly focus streaks. Do not make the requirements unnecessarily difficult or so easy that the entire collection can be unlocked quickly. Every locked tree must clearly show all requirements, for example “10,000/10,000 Focus Coins, 8/8 Trees Unlocked, 4.2/5 Focus Hours,” so users immediately understand what they need. Include around 30–40 trees with a sensible progression from common to rare to legendary, using locally created SVG/CSS/vector-style illustrations rather than copyrighted external images. Users should be able to unlock trees by spending Focus Coins once all requirements are satisfied and select any unlocked tree as their active tree; the active tree appears inside the timer. Allow users to end a focus session before the planned duration, but show a confirmation explaining how much time they completed; never remove coins they already legitimately earned, but an early-ended session should not count as a completed planned session. Completing the originally planned duration may provide a small completion bonus, but the main reward must remain 10 coins per completed focus minute. Include a Tasks section where users can create, select, filter and complete tasks, with active and completed tasks, categories, optional descriptions and task history; completed sessions should record the task, category, duration, coins earned and tree used. Include a Forest section showing all unlocked and locked trees, their requirements, progress and selection controls. Include a Statistics/Insights section that uses only the user's real stored data and contains clear graphs to help the user understand their productivity. Include a line graph for focus time over the last 7 days, 30 days or 3 months, a graph showing completed sessions over time, and a category chart showing how the user's focus time is distributed between Study, Coding, Research, Writing, Creative, Work, Personal and Other. Also show total focus time, today's focus time, weekly and monthly focus time, total sessions, today's sessions, average session length, longest session, current streak, longest streak, total coins earned, coins spent and trees unlocked. Add a weekly summary showing total focus hours, sessions, coins earned, best focus day and average session length, and provide simple personalized insights based only on real data, such as identifying the user's most common task category or strongest focus day; if there is insufficient data, show a friendly message asking the user to complete more sessions instead of displaying fake data. Use localStorage for all persistence including tasks, session history, coins, trees, settings, active tree, statistics, streaks and theme so refreshing the browser never removes progress. Include light and dark mode, notification sound when a timer finishes, browser notifications where supported, responsive mobile and desktop layouts, accessible controls, clean typography and a calm nature-inspired visual style. The timer must remain the visual centerpiece and the interface should feel like a peaceful digital forest rather than a generic productivity dashboard. Use React, TypeScript and Vite only; do not use Python, a backend, database, authentication or external APIs. Keep the code modular, readable and open-source ready, with reusable components and separated application logic. Every button and interaction must actually work; do not create a visual-only mockup. The final application should provide a balanced long-term progression where users are rewarded for genuine focused work and can gradually build their own digital forest.
